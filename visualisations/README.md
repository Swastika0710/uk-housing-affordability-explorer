# Visualisations

The interactive charts are generated in the browser by `app.js` using Chart.js.

## Charts

- **Affordability trend:** compares the price-to-earnings ratio over time for two selected regions.
- **Regional comparison:** compares affordability ratios across all UK regions for the selected year.

## Accessibility

Both charts include descriptive `aria-label` attributes so screen-reader users can understand their purpose.

## Colour thresholds

- Lower: below 6
- Moderate: 6 to 7.9
- High: 8 to 9.9
- Very high: 10 or above

These thresholds are used consistently for the pressure label and chart colours.
